Privacy policy – Offline Markdown Viewer

Publisher: FroggyBit Labs · Last updated: 2026-11-16

In short: Offline Markdown Viewer does not collect, transmit, share or sell any data. Everything happens on your device, inside your browser. Offline Markdown Viewer has no dependency on any remote program or service: everything it needs is bundled in the extension. Only you decide which external content, if any, your own documents may load.

What the extension does with your files

Offline Markdown Viewer reads Markdown files that you open (or drop into its viewer page) and renders them locally in your browser. File contents are never uploaded, copied to a server or shared with anyone.

What is stored on your device

Offline Markdown Viewer uses the browser's local extension storage (storage permission) for two things only:

  • Appearance settings: theme, colors, text size, font, and similar options.
  • Pins that you set on lines of a document: the line number, a short excerpt of that line (up to 80 characters), the time it was set, and an identifier of the document (the file address for files opened directly in the browser, or the file name plus its first line in the viewer page).
  • Remote images setting: whether the option is on, and the list of sites you typed (off and empty by default).

This data stays in your browser profile on your device. It is not synchronized through your browser account and is not sent anywhere. You can delete pins from the "Pins" panel ("Clear all" or "Remove"), and you can delete everything by removing the extension or clearing the extension's data in your browser.

Network access, analytics and third parties

  • By default Offline Markdown Viewer makes no network requests: remote images and other remote resources inside a Markdown file are blocked, not loaded.
  • Optional, off by default: if you turn on "Remote images" and list some sites, your browser loads images from those sites only (the https:// or http:// addresses you typed), for documents opened directly in the browser. Those sites see your IP address and when you open the document, like any website you visit, and your browser may send them the cookies it already holds for them. Offline Markdown Viewer adds no referrer and no identifier, and sends nothing to FroggyBit Labs. You can turn this off at any time. Network folders (for example \\server\share\) work the same way, for servers you list: the server sees your request, and Windows may send it your sign-in details, so list only servers you trust.
  • Offline Markdown Viewer contains no analytics, advertising, tracking or telemetry, and no code is downloaded from elsewhere.
  • Offline Markdown Viewer does not use third-party services. The libraries it needs (marked, DOMPurify, Mermaid) are bundled inside the extension.
  • Links in a document that you click open in a new browser tab like any other link; Offline Markdown Viewer does not track them.

Permissions

  • storage: to keep the settings and pins described above.
  • Access to local Markdown files (.md, .markdown, .mdown) so they can be rendered automatically. This requires your explicit consent in the browser ("Allow access to file URLs"). Offline Markdown Viewer does not read any other page.

Use of data

Since Offline Markdown Viewer does not collect user data, it does not sell it, transfer it to third parties, use it for advertising, or use it to determine creditworthiness or for lending purposes.

Children

Offline Markdown Viewer collects no data from anyone, including children.
