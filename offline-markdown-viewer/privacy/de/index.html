Datenschutzerklärung – Offline Markdown Viewer

Herausgeber: FroggyBit Labs · Zuletzt aktualisiert: 2026-11-16

Übersetzung der englischen Fassung; bei Abweichungen gilt die englische Fassung.

Kurz gesagt: Offline Markdown Viewer erhebt, übermittelt, teilt oder verkauft keinerlei Daten. Alles geschieht auf Ihrem Gerät, in Ihrem Browser. Offline Markdown Viewer hängt von keinem externen Programm und keinem externen Dienst ab: Alles, was es braucht, ist in der Erweiterung enthalten. Nur Sie entscheiden, welche externen Inhalte Ihre eigenen Dokumente gegebenenfalls laden dürfen.

Was die Erweiterung mit Ihren Dateien macht

Offline Markdown Viewer liest Markdown-Dateien, die Sie öffnen (oder in die Viewer-Seite ziehen), und stellt sie lokal in Ihrem Browser dar. Dateiinhalte werden nie hochgeladen, auf einen Server kopiert oder an irgendjemanden weitergegeben.

Was auf Ihrem Gerät gespeichert wird

Offline Markdown Viewer nutzt den lokalen Erweiterungsspeicher des Browsers (Berechtigung storage) nur für zwei Dinge:

  • Einstellungen zum Erscheinungsbild: Design, Farben, Textgröße, Schriftart und ähnliche Optionen.
  • Markierungen, die Sie auf Zeilen eines Dokuments setzen: die Zeilennummer, ein kurzer Auszug dieser Zeile (bis zu 80 Zeichen), der Zeitpunkt des Setzens und eine Kennung des Dokuments (die Dateiadresse bei direkt im Browser geöffneten Dateien, oder der Dateiname samt erster Zeile auf der Viewer-Seite).
  • Einstellung für externe Bilder: ob die Option eingeschaltet ist, und die Liste der Websites, die Sie eingegeben haben (standardmäßig aus und leer).

Diese Daten bleiben in Ihrem Browserprofil auf Ihrem Gerät. Sie werden nicht über Ihr Browserkonto synchronisiert und nirgendwohin gesendet. Sie können Markierungen im Bereich „Markierungen“ löschen („Alle löschen“ oder „Entfernen“) und alles entfernen, indem Sie die Erweiterung deinstallieren oder ihre Daten im Browser löschen.

Netzwerkzugriff, Analyse und Dritte

  • Standardmäßig stellt Offline Markdown Viewer keine Netzwerkanfragen: Externe Bilder und andere externe Ressourcen in einer Markdown-Datei werden blockiert und nicht geladen.
  • Optional, standardmäßig aus: Wenn Sie „Externe Bilder“ einschalten und Websites auflisten, lädt Ihr Browser Bilder nur von diesen Websites (den https://- oder http://-Adressen, die Sie eingegeben haben), bei Dokumenten, die direkt im Browser geöffnet werden. Diese Websites sehen Ihre IP-Adresse und wann Sie das Dokument öffnen, wie bei jeder Website, die Sie besuchen, und Ihr Browser kann ihnen die Cookies senden, die er bereits für sie gespeichert hat. Offline Markdown Viewer fügt keine Herkunftsseite und keine Kennung hinzu und sendet nichts an FroggyBit Labs. Sie können dies jederzeit ausschalten. Netzwerkordner (zum Beispiel \\Server\Freigabe\) funktionieren genauso, für Server, die Sie auflisten: Der Server sieht Ihre Anfrage, und Windows kann ihm Ihre Anmeldedaten senden; listen Sie daher nur vertrauenswürdige Server auf.
  • Offline Markdown Viewer enthält keine Analyse-, Werbe- oder Tracking-Funktionen und keine Telemetrie, und es wird kein Code von anderswo heruntergeladen.
  • Offline Markdown Viewer nutzt keine Dienste Dritter. Die benötigten Bibliotheken (marked, DOMPurify, Mermaid) sind in der Erweiterung enthalten.
  • Links in einem Dokument, die Sie anklicken, öffnen sich wie jeder andere Link in einem neuen Browser-Tab; Offline Markdown Viewer verfolgt sie nicht.

Berechtigungen

  • storage: um die oben beschriebenen Einstellungen und Markierungen zu speichern.
  • Zugriff auf lokale Markdown-Dateien (.md, .markdown, .mdown), damit sie automatisch dargestellt werden können. Dafür ist Ihre ausdrückliche Zustimmung im Browser nötig („Zugriff auf Datei-URLs zulassen“). Offline Markdown Viewer liest keine anderen Seiten.

Verwendung von Daten

Da Offline Markdown Viewer keine Nutzerdaten erhebt, verkauft es sie nicht, gibt sie nicht an Dritte weiter, nutzt sie nicht für Werbung und nicht zur Bonitätsprüfung oder für Kreditentscheidungen.

Kinder

Offline Markdown Viewer erhebt von niemandem Daten, auch nicht von Kindern.
