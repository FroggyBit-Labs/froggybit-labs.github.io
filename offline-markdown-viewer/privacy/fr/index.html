Politique de confidentialité – Offline Markdown Viewer

Éditeur : FroggyBit Labs · Dernière mise à jour : 2026-11-16

Traduction de la version anglaise, qui fait foi en cas de divergence.

En bref : Offline Markdown Viewer ne collecte, ne transmet, ne partage et ne vend aucune donnée. Tout se passe sur votre appareil, dans votre navigateur. Offline Markdown Viewer ne dépend d'aucun programme ni service distant : tout ce dont il a besoin est inclus dans l'extension. Vous seul décidez du contenu externe, le cas échéant, que vos propres documents peuvent charger.

Ce que l'extension fait de vos fichiers

Offline Markdown Viewer lit les fichiers Markdown que vous ouvrez (ou déposez dans sa page de lecture) et les affiche localement dans votre navigateur. Le contenu des fichiers n'est jamais envoyé, copié sur un serveur ni partagé avec qui que ce soit.

Ce qui est enregistré sur votre appareil

Offline Markdown Viewer utilise le stockage local de l'extension du navigateur (autorisation storage) pour deux choses seulement :

  • Les réglages d'apparence : thème, couleurs, taille du texte, police et options similaires.
  • Les points d'étape que vous posez sur des lignes d'un document : le numéro de ligne, un court extrait de cette ligne (80 caractères au plus), l'heure de la pose et un identifiant du document (l'adresse du fichier pour les fichiers ouverts directement dans le navigateur, ou le nom du fichier suivi de sa première ligne dans la page de lecture).
  • Le réglage des images distantes : si l'option est activée, et la liste de sites que vous avez saisie (désactivée et vide par défaut).

Ces données restent dans votre profil de navigateur, sur votre appareil. Elles ne sont pas synchronisées via votre compte de navigateur et ne sont envoyées nulle part. Vous pouvez supprimer des points d'étape depuis le panneau « Étapes » (« Tout effacer » ou « Retirer »), et tout supprimer en désinstallant l'extension ou en effaçant ses données dans votre navigateur.

Accès réseau, mesure d'audience et tiers

  • Par défaut, Offline Markdown Viewer n'effectue aucune requête réseau : les images et autres ressources distantes d'un fichier Markdown sont bloquées, pas chargées.
  • Facultatif, désactivé par défaut : si vous activez « Images distantes » et listez des sites, votre navigateur charge les images de ces sites uniquement (les adresses https:// ou http:// que vous avez saisies), pour les documents ouverts directement dans le navigateur. Ces sites voient votre adresse IP et le moment où vous ouvrez le document, comme n'importe quel site que vous visitez, et votre navigateur peut leur envoyer les cookies qu'il détient déjà pour eux. Offline Markdown Viewer n'ajoute aucune page d'origine ni aucun identifiant, et n'envoie rien à FroggyBit Labs. Vous pouvez le désactiver à tout moment. Les dossiers réseau (par exemple \\serveur\partage\) fonctionnent de la même façon, pour les serveurs que vous listez : le serveur voit votre demande, et Windows peut lui envoyer vos informations de connexion ; ne listez donc que des serveurs de confiance.
  • Offline Markdown Viewer ne contient aucun outil de mesure d'audience, de publicité, de suivi ni de télémétrie, et aucun code n'est téléchargé depuis un autre site.
  • Offline Markdown Viewer n'utilise aucun service tiers. Les bibliothèques dont il a besoin (marked, DOMPurify, Mermaid) sont incluses dans l'extension.
  • Les liens d'un document sur lesquels vous cliquez s'ouvrent dans un nouvel onglet comme n'importe quel lien ; Offline Markdown Viewer ne les suit pas.

Autorisations

  • storage : pour conserver les réglages et les points d'étape décrits ci-dessus.
  • Accès aux fichiers Markdown locaux (.md, .markdown, .mdown) pour les afficher automatiquement. Cela exige votre consentement explicite dans le navigateur (« Autoriser l'accès aux URL de fichiers »). Offline Markdown Viewer ne lit aucune autre page.

Utilisation des données

Comme Offline Markdown Viewer ne collecte aucune donnée d'utilisateur, il ne la vend pas, ne la transfère pas à des tiers, ne l'utilise pas à des fins publicitaires ni pour évaluer la solvabilité ou accorder un crédit.

Enfants

Offline Markdown Viewer ne collecte de données auprès de personne, y compris des enfants.

Modifications de cette politique

Si cette politique change, la nouvelle version sera publiée à cette adresse avec une date mise à jour.
